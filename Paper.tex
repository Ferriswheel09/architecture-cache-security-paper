\begin{abstract}
    Caches were first introduced to modern systems in order to both retrieve and store memory closer to the central processing unit but also to reduce time on subsequent memory requests on cache hits. However, recent attack patterns have revealed themselves based on utilizing the cache, branch prediction, and fault handling. 
    In this paper, I put forward a brief overview of the cache and a deep dive into attacks such as Spectre and Meltdown attacks, which utilize the cache in those attacks. I will also discuss mitigations provided for those attacks and what other work is being developed. 
\end{abstract}
